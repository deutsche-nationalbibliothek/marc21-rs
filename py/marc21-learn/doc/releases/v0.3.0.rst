==================
marc21-learn 0.3.0
==================

*Release date: November 24, 2026.*

Version ``0.3.0`` introduces the :py:mod:`marc21_learn.pid` module, which
contains various utility functions for working with persistent identifiers
(PIDs). In this initial release of the module, a set of functions for working
with ISBNs is provided.

Benchmarks
----------

The following benchmark compares the validation of ISBNs across different
Python libraries. Since the API and validation behavior differ among the
individual libraries, a test set was compiled consisting of 8,614,431 ISBNs,
all of which begin with the prefix “978” and are exactly 13 characters long.
If a library provided a specialized function for validating an ISBN-13, that
function was used preferentially. All test scripts have in common that they
read the test set using Python’s `csv.DictReader` and process it sequentially.
Parallelization across multiple threads was not used. When applied to the test
set, each library returned the same result of 35 invalid ISBNs.


The test set was compiled as follows based on the current data export from the
German National Library and the command-line tool `marc21`_:

.. code-block:: console

	$ marc21 select -s '020.a' DNB.mrc.gz \
		| rg '^978' \
		| awk 'length($0) == 13' \
		| sed '1s/^/isbn\n/' \
		> isbn13.csv

The metrics were measured using `hyperfine`_:

.. code-block:: console

	hyperfine -S --warmup 2 --min-runs 10 --metrics time \
		--export-json results.json --export-markdown results.md \
		--prepare 'sync; echo 3 | sudo tee /proc/sys/vm/drop_caches' \
		-n 'marc21-learn' './marc21-learn-validate.py ~/tmp/isbn13.csv' \
		-n 'isbnlib' './isbnlib-validate.py ~/tmp/isbn13.csv' \
		-n 'isbn-pure' './isbn-pure-validate.py ~/tmp/isbn13.csv' \
		-n 'is-isbn' './is-isbn-validate.py ~/tmp/isbn13.csv' \
		-n 'pydantic' './pydantic-isbn-validate.py ~/tmp/isbn13.csv' \
		-n 'pyisbn' './pyisbn-validate.py ~/tmp/isbn13.csv'
