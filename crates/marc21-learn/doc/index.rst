``marc21-learn`` is a toolkit that bridges the gap between the `MARC
21`_ data format and the machine learning library `scikit-learn`_. For
example, it provides functions for transforming records directly into a
`Polars DataFrame`_.

.. _MARC 21: https://www.loc.gov/marc
.. _scikit-learn: https://scikit-learn.org
.. _Polars Dataframe: https://pola.rs
